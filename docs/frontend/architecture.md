# Frontend: architecture

## 1) Слои и потоки данных

1. **App layer (`src/app`)**
   - Инициализирует глобальные провайдеры, роутинг и guards.
   - Контролирует глобальные cross-cutting concerns (i18n, notifications).
2. **Pages layer (`src/pages`)**
   - Экранный orchestration: собирает фичи, hooks, сервисы, UI-компоненты.
   - Не должен дублировать транспортную логику API/WS.
3. **Features layer (`src/features`)**
   - Локализует бизнес-функции по use-case.
   - Взаимодействует с `services`, `store`, `shared`.
4. **Entities layer (`src/entities`)**
   - Базовые доменные модели/типы и связанные упрощённые представления.
5. **Shared layer (`src/shared`)**
   - Общие UI- и utility-примитивы, схема валидации, абстракции, которые не зависят от конкретного домена.

## 2) Маршрутизация и доступ

- Роуты централизованы в `src/app/router/routeMap.ts` и `src/app/router/AppRouter.tsx`.
- Отложенная загрузка страниц находится в `src/app/router/lazyPages.ts`.
- Ограничение доступа выполняют guards:
  - `AuthGuard` — только для авторизованных;
  - `GuestGuard` — только для гостей;
  - `AdminGuard` — только для администратора.

## 3) UI и дизайн-система

- Общие стили и токены лежат в `src/theme/*`.
- Переиспользуемые UI-элементы — в `src/components/ui/*` и `src/shared/ui/*`.
- Страницы используют эти примитивы, а не создают дублирующиеся компоненты по месту.

## 4) Hooks и границы переиспользования

- `src/hooks/*` содержит hooks уровня приложения/домена (`useAuth`, `useGames`, `useSockets`, `useDialogA11y`, `useInterval`).
- Hooks не должны содержать JSX-разметку и должны быть ориентированы на повторное использование между страницами/фичами.

## 5) Рекомендации по расширению UI

- Новые пользовательские сценарии сначала оформлять как `feature`, а потом подключать в `page`.
- Новые визуальные элементы общего назначения добавлять в `components/ui` или `shared/ui`.
- Перед созданием нового компонента проверять существующие примитивы (Button, Input, Modal, Table, Tabs, Toast и т.д.).
- Все новые тексты UI сразу выносить в i18n-ресурсы (`locales/ru/common.ts` и `locales/en/common.ts`).
