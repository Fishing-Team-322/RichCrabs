# Richcrab workspace: архитектура

## Высокоуровневая схема

- Каждый домен реализован как отдельный сервис-крейт.
- Общие функции (конфиг, БД, id, ошибки, redis-клиент) вынесены в `shared`.
- gRPC типы генерируются из `proto` и используются во всех сервисах.

## Межсервисные зависимости

- `game` использует `quiz` и `entitlements`.
- `bot` и `bot_runner` интегрируются с игровыми сценариями.
- `auth` обеспечивает user/session связанную функциональность.

## Инфраструктурные зависимости

- PostgreSQL для персистентных доменных данных.
- Redis для кеша, ephemeral state и очередей.
