# Shared crate: API модули

## `config`

- Общие структуры конфигурации и env-парсинг.

## `db` / `redis_client`

- Создание подключений/пулов к инфраструктуре.

## `errors`

- Базовые типы и обертки ошибок для сервисного слоя.

## `ids`, `time`, `crypto`

- Утилиты для идентификаторов, времени и криптографических операций.

## `observability`

- Набор функций для инициализации telemetry/tracing.
