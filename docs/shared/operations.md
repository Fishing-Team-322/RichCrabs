# Shared crate: операции

## Проверка сборки

```bash
cd richcrab
cargo check -p shared
```

## Рекомендации по изменениям

- Сначала обновляйте `shared`, затем адаптируйте потребителей в сервисах.
- Избегайте лишних breaking изменений публичных функций.
- Добавляйте unit tests на низкоуровневые утилиты.

## Диагностика

- Если сервисы падают на старте одинаково, часто проблема находится в shared-конфигурации или инфраструктурных клиентах.
