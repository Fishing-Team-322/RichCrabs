# Shared crate: обзор

`richcrab/shared` — общая библиотека для Rust-сервисов.

## Назначение

- Избежать дублирования кросс-сервисных утилит.
- Централизовать конфигурацию, инфраструктурные клиенты и общие типы ошибок.

## Основные модули

- `config`
- `db`
- `redis_client`, `redis_keys`
- `errors`
- `ids`, `time`
- `crypto`
- `observability`
