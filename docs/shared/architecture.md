# Shared crate: архитектура

## Принципы

- Модули должны быть domain-agnostic и reusable.
- Публичные API в `shared` должны быть стабильными между сервисами.
- В `shared` не переносится высокоуровневая бизнес-логика отдельных сервисов.

## Внутренние зоны ответственности

- Конфигурация: загрузка env-настроек.
- Инфраструктура: подключения к БД/Redis.
- Безопасность: базовые crypto-функции.
- Наблюдаемость: tracing/metrics bootstrap.
