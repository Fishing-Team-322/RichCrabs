# Tools: архитектура

## smoke_load

Утилита выполняет сценарий:

1. создаёт room через `GameService`;
2. генерирует join tickets через `JoinService`;
3. выполняет последовательные join операций;
4. запускает игру (`start_game`).

## Зависимости

- gRPC клиенты из crate `proto`.
- Конфигурация через env-переменные.
