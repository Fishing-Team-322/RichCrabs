# Tools: обзор

Инструменты проекта сосредоточены в `richcrab/tools/` и вспомогательных скриптах модулей.

## Текущий ключевой инструмент

- `richcrab/tools/smoke_load` — утилита нагрузочного smoke-теста через gRPC.

## Цель

- Быстрая проверка работоспособности game/join сценариев.
- Базовая оценка поведения сервисов при множественных join-операциях.
