# RichCrabs

![alt text](docs/rich_crab.png)

## О проекте

RichCrabs — платформа для проведения викторин в реальном времени с поддержкой игровых комнат, управления квизами, подписок и интеграции с Telegram-ботами. Проект объединяет несколько backend-сервисов, Python gateway и frontend-приложение в единую инфраструктуру, которую можно развернуть локально через Docker Compose.

Репозиторий включает не только runtime-компоненты, но и документацию по архитектуре, API, протоколам и запуску окружения. Это позволяет использовать RichCrabs как для разработки и тестирования продукта, так и как базу для дальнейшего развития отдельных сервисов.
